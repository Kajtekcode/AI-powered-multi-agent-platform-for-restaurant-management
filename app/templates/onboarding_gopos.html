Połącz kasę GoPOS

Wpisz dane dostępowe z panelu GoPOS. Pobierzemy historię zamówień, pozycji menu i grafików.

🔒 Łączymy się tylko do odczytu. Niczego nie zmieniamy ani nie zapisujemy w Twojej kasie. Klucze przechowujemy zaszyfrowane.
Gdzie znajdę te dane?
W panelu GoPOS: Ustawienia → API / Integracje → utwórz aplikację (typ: tylko odczyt).
  1. Organization ID — identyfikator Twojej organizacji
  2. Client ID — identyfikator aplikacji API
  3. Client Secret — klucz tajny (pokazywany raz)
⚠
Klucz zostanie zaszyfrowany i nie będzie nigdzie pokazywany ponownie.
